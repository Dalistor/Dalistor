## 🚀 Projetos em destaque

### 🧭 [Centaur-Driven](https://github.com/Dalistor/Centaur-Driven)

Uma metodologia e um conjunto de ferramentas para desenvolvimento de software com agentes de IA.

O Centaur-Driven explora uma forma de desenvolvimento onde o humano continua responsável por **intenção, arquitetura, regras e limites do sistema**, enquanto agentes de IA podem assumir partes cada vez maiores da implementação.

O projeto trabalha com conceitos como:

- contratos versionados;
- especificações estruturadas;
- requisitos funcionais e não funcionais;
- casos de uso;
- TDD;
- rastreabilidade entre regras, código e testes;
- evidências de validação;
- memória e contexto para agentes;
- múltiplos agentes trabalhando em conjunto;
- visualização da arquitetura e dos fluxos do sistema;
- integração com VS Code.

A ideia é explorar como o desenvolvimento de software pode funcionar quando **ler e escrever manualmente todo o código deixa de ser a principal interface de desenvolvimento**.

### 🛠️ Workerrs

Plataforma voltada para conectar clientes a profissionais de serviços por meio de uma experiência conversacional.

O projeto utiliza automação e Inteligência Artificial para entender a necessidade do usuário, localizar profissionais compatíveis e facilitar o contato por meio do WhatsApp.

Entre os pontos explorados no projeto estão:

- agentes de IA para atendimento conversacional;
- integração com WhatsApp;
- busca e recomendação de profissionais;
- filtragem por localização;
- perfis de prestadores de serviço;
- imagens e descrições dos profissionais;
- assinaturas para prestadores;
- divulgação segmentada por região;
- automação do fluxo entre cliente e profissional.

O Workerrs também funciona como um experimento de **produto, monetização e aquisição de usuários**, indo além da implementação técnica.

## 🧩 Como trabalho

Não costumo me definir por linguagens ou frameworks específicos.

Linguagens são ferramentas, e a escolha depende do problema que precisa ser resolvido.

Meu fluxo atual de desenvolvimento se aproxima de:

**Problema → Arquitetura → Requisitos → Contratos → Implementação assistida por IA → Testes → Validação**

Hoje, meu foco está principalmente em entender:

- o que o sistema precisa fazer;
- como suas partes devem se relacionar;
- onde cada responsabilidade deve ficar;
- como os dados devem fluir;
- como validar o comportamento produzido pela IA.
